# transport-cards-db

![License](https://img.shields.io/badge/license-MIT-green)

Консольная программа на C++ для учёта транспортных карт: меню, операции с балансом, поиск и работа с файлами.

## О проекте

Программа ведёт список транспортных карт: добавление и удаление, пополнение и проверка баланса,
поиск по номеру и по владельцу, сохранение и загрузка из файла. Делал её по ходу курсовой работы, поэтому
ранние версии собираются в `archive/`: сейчас это версия на структурах и массивах, дальше — переход
к классам и наследованию.

## Что умеет

- добавление карты с автоматической генерацией уникального номера;
- три типа карт: безлимитная, карта-кошелёк, разовая;
- просмотр всех карт в виде таблицы;
- удаление карты по номеру с подтверждением;
- пополнение баланса, дней действия или количества поездок;
- проверка остатка по номеру карты;
- поиск карты по номеру и поиск всех карт конкретного человека;
- сохранение базы в файл и загрузка из файла.

## Формат данных

Текстовый файл. Сначала количество записей, затем каждая карта в четыре строки:

```
<количество>
<номер>
<тип>
<владелец>
<дни> <баланс> <поездки>
```

Пример (`data/cards.txt`):

```
2
31099
Карта кошелек
Иванов С.Е.
0 12 0
35726
Разовая
Петров Ю.С.
0 0 12
```

## Сборка и запуск

Нужны Windows и Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++».

В Visual Studio: откройте `transport-cards-db.sln`, соберите `Release | x64`, запустите.

Через MSBuild:

```powershell
msbuild transport-cards-db.sln /p:Configuration=Release /p:Platform=x64
```

Через CMake:

```powershell
cmake -B build -A x64
cmake --build build --config Release
```

После сборки запустите `transport-cards-db.exe`:

- Visual Studio / MSBuild — `x64\Release\`;
- CMake — `build\Release\`.

Выберите пункт 9 и укажите файл `data/cards.txt`, чтобы загрузить пример базы.

## Как устроено

Сейчас вся логика в одном файле `src/main.cpp`: структура `Card` и функции для работы с массивом
карт. Меню программы вызывает нужную функцию по номеру пункта.

Структура проекта:

```
transport-cards-db/
├── src/                  # текущая версия
│   └── main.cpp
├── data/                 # примеры базы данных
├── archive/              # ранние этапы (01…)
│   └── 01-arrays/
│       └── main.cpp
└── docs/
```

## В разработке

- рефакторинг единого `main.cpp` в классы с наследованием;
- вынос логики из меню в отдельный класс базы карт;
- расширение поиска и сортировок.
