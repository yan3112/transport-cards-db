# Этапы развития проекта

Проект рос по темам курса: от простых структур и массивов к классам и наследованию. Ранние
версии сохраняются в `archive/`, актуальная — в `src/`.

## 01-arrays — сделано

Версия на структурах и статическом массиве (`archive/01-arrays/main.cpp`):

- структура `Card` (тип, номер, владелец, дни, баланс, поездки);
- статический массив карт и счётчик элементов;
- добавление карты с генерацией уникального номера;
- удаление карты со сдвигом элементов;
- пополнение и проверка баланса для трёх типов карт;
- поиск по номеру и по владельцу;
- сохранение и загрузка из файла;
- консольное меню.
